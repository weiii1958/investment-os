投資總經儀表板

我做投資時常遇到：標的研究可以很深，但一到加碼或降曝險，總經資料卻散在各個網站，每次都要重找。

所以我做了一個自己的儀表板，把日常會用的訊號集中在同一頁。

網站：https://weiii1958.github.io/investment-os/

下面說明各區塊為什麼加、怎麼看。

破線水位／大盤均線（QQQ、VOO、台股、SOX）

為什麼加 個股再強，也難長期逆大盤。均線用來判斷風險偏好的大方向：結構偏多，還是該收斂曝險。
SOX（半導體）對 QQQ 的相對強弱，用來判斷這一輪主線還在不在晶片／科技上。
怎麼看
  • 對照 SMA 30／60／200，以收盤價為準。
  • 站上的均線愈多 → 結構愈完整。
  • 先破短均（30）→ 先降節奏；連 60、200 也破 → 系統性轉弱機率上升。
  • SOX 明顯弱於 QQQ → 半導體主線退潮，選股要更挑、更慢。

我的紀律卡（破線減碼、部位上限）

為什麼加 只知道「破線了」不夠。要事先寫死：破哪一條、砍多少、單檔最多幾％。否則當下容易心軟，或砍太慢。
怎麼看
  • 破線階梯：依 30 → 60 → 200，逐步降曝險；通常先處理相對弱的標的。
  • 部位上限：常態單檔上限多少；什麼條件齊全才允許拉高。
  • 每天看水位時，直接對照這張卡，避免臨場重新談判規則。

VIX

為什麼加 股價不只反映基本面，也反映流動性與情緒。VIX 是選擇權市場定出來的波動／恐慌溫度，適合作為市場壓力計。
怎麼看
  • 低位橫盤：波動被壓住，既有趨勢較容易延續。
  • 快速抬升：避險需求上升，回撤、殺估值較容易出現。
  • 從高位回落：恐慌減退；再對照均線、HY 利差，確認是否真的回穩。

台股融資維持率／融資餘額

為什麼加 台股有明顯的融資籌碼結構。維持率看「槓桿多頭緊不緊」，餘額看「市場還在加槓桿還是在去槓桿」。這會影響短線賣壓與反彈品質。
怎麼看
  • 維持率往下：擔保品相對借款變薄，融資戶壓力變大。
  • 餘額下降：市場在減融資、去槓桿。
  • 兩者同降：較常伴隨停損／斷頭式賣壓。
  • 維持率止跌回升、餘額不再大降：籌碼壓力緩解的早期跡象。

Fed 意圖：整面證據牆怎麼用

為什麼加 美股定價高度依賴「錢的價格」與「經濟會不會硬著陸」。Fed 路徑一變，成長股估值與風險偏好會先動。所以要把利率、通膨、就業、曲線、信用利差放在同一面牆交叉看，而不是只看單一新聞標題。
怎麼看（總覽） 最後要回答的是一句話：
現在比較像「通膨回落、可談寬鬆」，還是「就業／信用轉差、風險偏好該收」？

下面把牆上每個指標拆開。

基準利率（Fed Funds）與 Fed 總資產

為什麼加
  • 基準利率＝錢的價格（借錢貴不貴）。
  • 總資產（資產負債表）＝錢的數量（QT 收錢／擴表放錢）。
兩條軸要一起看，才不會只聽到「升息／降息」就下結論。
怎麼看
  • 利率維持高位很久：緊縮會慢慢傳到貸款與實體。
  • 開始降息：要分是通膨回落後的預防性，還是就業惡化後的急救。
  • 總資產往下：偏 QT（量緊）；持平：量的緊縮暫停；往上：流動性偏改善。

Truflation（日頻通膨感覺）

為什麼加 官方通膨（如 Core PCE）是月頻、較慢。Truflation 較接近「現在通膨往哪走」的日頻感覺，用來提早看方向與加速度，不必等下一次月報才反應。
怎麼看
  • 持續回落／低位盤整：通膨壓力緩，較支持「不必再暴力升息」、預防性寬鬆敘事較容易站住。
  • 突然回升並加速：市場可能更快修正降息預期（偏鷹），成長股短線常先承壓。
  • 和 Core PCE 對方向即可，不必死盯小數點；兩者背離時，先當警訊，等官方確認。

Core PCE（Fed 主要看的通膨）

為什麼加 這是 Fed 政策較核心的通膨錨（扣除食品、能源）。比 headline CPI 更能反映「消費替代後」的通膨，適合判斷政策空間。
怎麼看
  • 約在可控帶盤整、沒再加速：較不支持再次暴力升息。
  • 明顯偏高且重新上行：Fed 更難鬆，估值壓力上升。
  • 通膨好看但就業同步崩：比較像衰退式鬆綁，不是單純「通膨好了就全面做多」。

初領失業金／失業率

為什麼加 通膨決定 Fed「想不想鬆」，就業決定經濟「有沒有在裂開」。
  • 初領＝每週新申請失業救濟（流量、較快）。
  • 失業率＝有多少人沒工作（存量、較慢但全面）。
怎麼看
  • 初領穩定、沒明顯週週墊高：勞動市場流量還行。
  • 初領連續走高／明顯越過自己設定的警戒：裂開機率上升。
  • 失業率明顯上行且延續：全面衰退機率上升，風險資產常先殺估值再殺獲利。

美國 2Y／10Y 公債殖利率

為什麼加
  • 2Y 較貼近市場對未來 1～2 年 Fed 路徑的定價（短端）。
  • 10Y 較反映長期成長、通膨與期限溢酬（長端）。
兩者一起看，才知道市場在喊「更緊」還是「更鬆」，以及成長股估值壓力從哪來。
怎麼看
  • 2Y 快速上行：市場定價更鷹／更高更久 → 短端緊。
  • 2Y 快速下行：市場定價鬆綁；此時要分是預防性還是衰退式。
  • 10Y 明顯上行：長天期現金流折現變差 → 成長／高估值股常先受傷。
  • 10Y 下行若同時伴隨就業惡化、HY 急擴：較像避險湧入公債＋信用壓力，不是單純利多。

10Y−2Y 殖利率曲線

為什麼加 曲線告訴你短端與長端誰更緊。倒掛（短端高於長端）常代表市場認為「現在很緊，之後可能變冷」。
怎麼看
  • 持續倒掛且夠深：之後成長放緩／衰退風險偏高（有時間差，不是當天就崩）。
  • 倒掛翻正：不一定等於可以放鬆——有時是因為經濟變差、短端先掉才翻正。
  • 略為正但很薄：倒掛警訊可能減弱，但整體利率環境仍可能偏緊。

HY 信用利差（高收益債利差）

為什麼加 公債反映「無風險利率水位」；HY 利差反映「信用怕不怕、流動性緊不緊」。有時利率還穩，但信用已經先出問題。
怎麼看
  • 利差低、穩定：信用壓力不大。
  • 慢慢擴大：提高警覺。
  • 短時間急擴：信用／流動性壓力上升，常與風險資產回撤一起出現。
  • 從高位慢慢收斂：害怕在退，才比較適合重新考慮風險偏好。

Token 用量（AI 需求端）

為什麼加 這一輪很多供應鏈定價，建立在 AI 需求能不能延續。Token 用量是需求端的高頻體溫，用來檢查「敘事是否還有量能支撐」。
怎麼看
  • 總量往上：需求端偏熱，利於硬體／基建相關樂觀假設。
  • 走平或轉下：需求降溫，新開倉與延長樂觀要更保守。
  • 美／中拆解：看成長是誰在貢獻；主問題仍是總量方向有沒有延續。

庫存循環（ISM 差值＝新訂單 − 客戶庫存）

為什麼加 對供應鏈來說，庫存週期往往比 GDP 更直接：貨太少 → 催訂單、可能漲價；貨太多 → 砍單、降價、毛利受壓。這條線連到上游營收與毛利預期。
怎麼看
  • 差值＝新訂單 − 客戶庫存（兩個分數相減）。
  • 正值高且上升：訂單相對強、客戶貨偏少 → 偏補庫存。
  • 高正值開始回落：補庫存動能減弱；警惕「貨還在進、需求已慢」。
  • 轉負且下探：去庫存壓力大，砍單／降價機率上升。
  • 負值但止跌回升：可能接近出清尾聲。
差值是溫度計；要判斷比較像哪一階段，還要對照報價、庫存天數、法說內容。

FMS（機構經理人問卷）

為什麼加 價格不只反映基本面，也反映「錢站在哪一邊」。FMS 看機構現金、擁擠交易、景氣投票，用來掌握主流倉位與情緒位置。
怎麼看
  • 現金偏低：機構偏樂觀、手上子彈少。
  • 擁擠交易集中：單一主題過度擁擠時，逆向波動容易變大。
  • 著陸／通膨／Fed 預期：和上面 Fed 證據牆對照，看機構想法與實際數據有沒有裂縫。
有裂縫的地方，常是預期差值得追的起點。
這個儀表板很單純：把我投資真正會用到的總經與市場訊號寫清楚；之後也會依研究再新增。
