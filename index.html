應該怎麼看

  1. 維持率估算量什麼：全市場「融資多頭」擔保品市值 ÷ 融資金額（FinLab 口徑，含 ETF）。數字愈低＝槓桿多頭愈痛；≠證交所整戶，也≠你個人帳戶追繳數字。
  2. 融資餘額量什麼：上市＋上櫃融資金額合計（億）。上升＝市場還在加槓桿；下降＝融資退場／去槓桿。
  3. 兩者一起看：維持率急跌＋餘額續降 → 較像斷頭／停損賣壓釋放中；維持率回升且餘額止跌 → 籌碼較穩。單看一天高低不決策。
  4. 水位口訣（本站估算%）：剛融資約 166.7% → 框架參考 150% → 偏緊 140% → 130% 附近＝本序列極端底（如 2025 關稅戰）；個人追繳仍看券商整戶。
  5. 注意：不要跟 M 平方舊圖 140% 絕對值硬比。大盤加減碼仍以均線收盤破線為主訊號。

Fed 意圖

預防性降息 vs 衰退式降息 · 左卡右圖 · 自行判讀

央行政策與利率傳導 框架確定

Fed 用兩條軸：利率（錢的價格）與資產負債表（錢的數量／QT·QE）。先搞懂利率怎麼傳下去，再看下方證據牆（含總資產斜率）。

基準利率（Fed Funds）＝銀行隔夜拆借的官方參考利率，整個金融系統「借錢的底價」。 升息＝借錢變貴、壓通膨；降息＝借錢變便宜、刺激經濟。 Fed 總資產（WALCL）＝另一條軸：往下偏 QT、往上偏擴表、橫盤常是暫停縮表後的持平。

利率傳導（完整鏈）
  1. Fed 調升基準利率
  2. 銀行間隔夜利率上升
  3. 短期美債殖利率上升（2 年、3 個月…）← 日常盯 2Y
  4. 銀行存貸款利率上升（房貸、車貸、企業借款）
  5. 大家少借錢、少消費、少投資
  6. 通膨壓力下降（通常要幾個月到一年才明顯）
升息 → 成長股為何易受傷

美債等「現在就能拿的利息」變香 → 較不想買很貴的成長股。科技股很多價值在很遠以後的獲利；折現率變高 → 本益比被壓縮（殺估值），公司還沒變爛，股價常先跌。

升息太猛 → 衰退風險

借錢太貴 → 消費投資放緩 → 裁員 → 失業升 → 衰退。白話：升息是吃藥治通膨，藥下太猛副作用就是衰退。Fed 想要的是軟著陸——壓住通膨又不要硬著陸。

站上用法：基準利率＝錢的價格標籤；Fed 總資產＝錢的數量（QT／QE）； 2Y／10Y／曲線＝日常解讀（市場常比 Fed 早動）。時間差：債市幾天～幾週，貸款約 1～3 個月，實體經濟約 6～18 個月。

怎麼讀這區

  1. Fed 意圖＝劇本判斷：預防性＝經濟沒崩、通膨回落；衰退式＝失業惡化、信用緊。
  2. 先讀上方傳導：基準利率 → 短債 → 貸款 → 經濟；再看 FedWatch 自算（市場定價），再往下證據牆。
  3. 布局：左邊說明卡、右邊歷史圖（菲利浦＝散點路徑）。
  4. 已上線：基準利率、Fed 總資產（QT／QE）、FedWatch 自算、Truflation、初領、Core PCE、失業率、菲利浦、10Y／2Y、10Y−2Y、HY。
  5. 框架錨點：失業率約 4%；初領約 30 萬；Core PCE 約 2%～3%。

Token 總量趨勢（週）

怎麼讀 Token

  1. 先看粗線：升＝需求體溫還在；走平／降＝領先指標變冷，半導體新開倉更保守。
  2. 中美細線：誰在扛可以看，但不改變「總量有沒有升」的主判斷。
  3. 限制：OpenRouter≠全球真實總用量。原始排行：openrouter.ai/rankings

庫存循環（ISM 差值）

美國製造業 · 月頻溫度計

庫存循環與差值　 貨太少（補庫存）與貨太多（去庫存）的來回；供應鏈上比 GDP 更貼訂單／報價。 本站溫度計叫差值＝新訂單 − 客戶庫存（兩個分數相減，不是插值）。 新訂單高、客戶庫存低 → 正值大 → 偏補；縮小／轉負 → 動能轉弱或偏去。 大數字與粗線都是它。

ISM 問卷　 美國供應管理協會每月問製造業採購主管：訂單比上月強不強、客戶手上你的貨算多還少。 編成以 50 為界的指數（感覺調查，非實際噸數）。 這是美國製造業整體，不是半導體專屬。 看水平＋方向，≠直接等於四階段；連看數月，再用報價、庫存天數驗證。

差值走勢

主看粗線。虛線＋3＝框架「明顯正值」錨點。細線＝拆解，可忽略。

怎麼判斷四階段

  1. 看差值：水平＋近幾個月方向（單月雜訊大）。
  2. 連看 3～6 個月：確認升／平／降，不要單點定案。
  3. 驗證現場：報價漲不漲、庫存天數升或降、法說講缺貨還是砍單。
  4. 才說「比較像」哪一階段：差值偏補／去；主動／被動靠驗證分辨。常見陷阱：差值還很高正，但報價不動、庫存天數上升 → 更像②，不是永遠①。
  5. 部位：仍過第二層破線。

FMS 月度問卷

機構經理人在忙什麼 · 參考用，不作買賣燈

FMS＝美銀（BofA）每月問全球基金經理人：手上現金多少、覺得景氣怎麼走、錢擠在哪裡。 數字經美股 Insight整理後自動抽進本站。重點看三件事：現金夠不夠（彈藥）、大家是否擠同一邊（擁擠）、景氣劇本偏樂觀還悲觀。

現金占 AUM 歷史

越低＝越敢把錢投入市場（彈藥越少）。虛線＝框架警戒約 4%。

著陸預期歷史

經理人投票：未來一年全球經濟偏硬著陸／軟著陸／不著陸。只有原文有寫的月份才會出現。

怎麼讀 FMS

  1. 現金 < 約 4%：偏樂觀、手上子彈少；框架寫極低時提高警覺，不單獨當賣出訊號。
  2. 擁擠交易很高：多數人站同一邊，逆向空間要更小心，新開倉看估值與預期差。
  3. 著陸／通膨／Fed：這是「經理人怎麼想」，可和 Fed 意圖區的實際數據交叉，找預期差。
  4. MoM vs Absolute：MoM＝相對上個月加減碼；Absolute＝現在願意超配／低配誰。兩者一起看輪動方向。
